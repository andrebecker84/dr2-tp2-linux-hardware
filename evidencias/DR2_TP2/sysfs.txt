DISPOSITIVO ESCOLHIDO: /dev/sdf, o disco que guarda a raiz (findmnt -no SOURCE /)

ATRIBUTOS LIDOS EM /sys/block/sdf
- size .....................: 2147483648 setores de 512 bytes = 1024 GiB
- dev ......................: 8:80 (major:minor; o major 8 é o driver sd)
- ro / removable ...........: 0 / 0 (gravável e não removível)
- queue/rotational .........: 1 (o disco virtual se declara rotacional)
- logical/physical_block ...: 512 / 4096 bytes
- device/vendor e model ....: Msft Virtual Disk

OBSERVAÇÕES
- O sysfs não guarda arquivos em disco: cada leitura pede o valor ao kernel,
  que o gera na hora (um valor por arquivo, em texto).
- size conta sempre setores de 512 bytes, mesmo com bloco físico de 4096.
- rotational = 1 é o que o Hyper-V informa. O arquivo .vhdx está num SSD NVMe
  do Windows: o atributo descreve o disco virtual, não a mídia física.
- pwd -P mostra o caminho real: /sys/block/sdf é um link para
  /sys/devices/..., a posição do disco na árvore de barramentos (host SCSI,
  alvo, LUN e, por fim, o bloco).
